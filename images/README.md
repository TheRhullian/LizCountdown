# Como adicionar as fotos da Liz

O site já está pronto para mostrar as fotos — basta salvar os arquivos **nesta pasta** com os nomes exatos abaixo. Se a extensão do arquivo for diferente da indicada, é só avisar para ajustar `js/config.js`.

| Nome do arquivo | Onde aparece |
|---|---|
| `hero.jpg` | Foto principal, no topo do site (redonda) — ainda não adicionada |
| `foto1.jpeg` até `foto6.jpeg` | Galeria "nossos momentos" |

Não precisa usar todos os espaços da galeria — o que não existir simplesmente não aparece, sem quebrar o layout. Assim que você adicionar um arquivo com o nome certo e atualizar a página, a foto já aparece sozinha.

Dica: fotos na proporção retrato (vertical) ficam melhores na galeria.
